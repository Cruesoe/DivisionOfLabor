# Division of Labor

Splits RimWorld's broadest work types into focused jobs, so you can assign specialists instead of generalists.

## New work types

- **Nurse** — rescuing, taking patients to bed for operations, feeding colonists, prisoners and animals, hemogen, and visiting the sick. Doctors keep tending and surgery.
- **Butcher** — butcher table bills, for meat and kibble.
- **Deconstruct** — deconstructing, uninstalling, clearing space for blueprints, filling in pits, and removing floors, roofs and foundations.
- **Repair** — repairing and fixing broken-down buildings. Construction keeps building.

## Tidier Work tab

- Fishing sits next to Hunting, and plant cutting next to Growing.
- Dark study joins Research.
- Smoothing is Construction's lowest job, walls before floors.
- New colonies start with manual priorities turned on.
- Column headers are tilted so more work types fit on screen; the mod settings can turn them vertical, stack them, or leave them flat.
- Scroll over a priority box to change it.

## Supported mods

Folded in rather than left as separate columns:

- **Hospitality** — Recruiter and Diplomat join Warden.
- **Therapy** — therapy joins Warden.
- **Simple Improve** — improving joins Construction as its lowest job.
- **Recycle This** — recycling and destroying join Crafting.
- **Vanilla Books Expanded** — writing moves next to Art.
- **Dubs Bad Hygiene** — patient care joins Nurse.
- **Vehicle Framework** — vehicle repair and disassembly join Repair and Deconstruct.
- **VE Gravship** — gravship maintenance joins Repair.
- **Guarding Pawns + Keyz Allow Utilities** — finishing off joins guard duty.

## Compatibility

Safe to add to an existing save. Incompatible with Complex Jobs, Nurse Job, Smooth Walls then Floor, and Compact Work Tab, which is built in. Also works with Priority Master, Work Manager and Grouped Pawns Lists.
